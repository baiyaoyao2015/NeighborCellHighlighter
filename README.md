**这是一个轻量级插件，用于快速查看主小区及其邻区关系。**

  - 选择一个扇区以自动高亮显示（颜色可自定义）。
 
  - 读取邻层列表字段，并高亮显示所有对应的邻居（颜色可定制）。
 
  - 自动从主单元质心向所有相邻质心绘制线条。
 
  - 支持通过右键样式菜单选择重叠单元格。
 
  - 完全可定制的参数配置：您可以选择主小区ID字段、邻居列表字段，并设置高亮/线条颜色。
 
  - 与其他网络插件不同，此插件无需进行复杂的数据预处理。它直接从您的属性表中读取邻层列表字符串（以 “|” 分隔），这使得它在交互式地图查询时极为轻便且快速。
  
   **This is a lightweight plugin designed for quickly viewing the relationships between the primary cell and its neighboring cells.**
 - Select a sector to automatically highlight (color can be customized).
 - Read the adjacent layer list field and highlight all corresponding neighbors (color can be customized).
 - Automatically draw lines from the centroid of the main unit to all adjacent centroids.
 - Support selecting overlapping cells through the right-click style menu.
 - Fully customizable parameter configuration: You can select the primary cell ID field, neighbor list field, and set highlight/line colors.
 - This plugin does not require complex data preprocessing. It directly reads the adjacent layer list string (separated by '|') from your attribute table, making it extremely lightweight and fast for interactive map queries.

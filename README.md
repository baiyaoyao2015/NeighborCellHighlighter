**这是一个轻量级插件，用于快速查看主小区及其邻区关系。**

  -选择一个扇区以自动高亮显示（颜色可自定义）。
 
  -读取邻层列表字段，并高亮显示所有对应的邻居（颜色可定制）。
 
  -自动从主单元质心向所有相邻质心绘制线条。
 
  -支持通过右键样式菜单选择重叠单元格。
 
  -完全可定制的参数配置：您可以选择主小区ID字段、邻居列表字段，并设置高亮/线条颜色。
 
  -与其他网络插件不同，此插件无需进行复杂的数据预处理。它直接从您的属性表中读取邻层列表字符串（以 “|” 分隔），这使得它在交互式地图查询时极为轻便且快速。
